# Координация Codex и Antigravity

Цель: локальная Android-версия с качественной деревней и интерфейсом на доступных оригинальных ресурсах. Полный автономный клиент ещё не готов.

## Разделение ответственности

- Codex: существующие src/, jni/, AndroidManifest.xml, build.py, native-логика и интеграция.
- Antigravity: только parallel/antigravity/ и его собственный coordination/ANTIGRAVITY_REPORT.md.
- Карточки заданий coordination/tasks/ пишет Codex; Antigravity читает карточки, отмечает выполнение в своём отчёте. Общего автоматического диспетчера нет.
- Работать в этой же папке, без reset/clean/stash/checkout, массового форматирования и изменения файлов другого исполнителя. Не запускать параллельно общий build.py: его work-каталог общий. Свою сборку держать в parallel/antigravity/.../build/.
- Не публиковать и не отправлять наружу APK, библиотеки, дампы, данные деревни или аккаунта. Git локальный, remote не настроен.
- На телефоне работает только Codex. Antigravity не запускает ADB, Frida и не меняет оригинальную игру.

## Проверенное состояние

offline-combat-lab.apk: холодная загрузка таблиц/деревни, NPC-режим, высадка варвара, 2048 native-шагов, движение и урон. Панель текстовая.

Экспериментальная оригинальная оболочка: штатно загружаются support и libg, createGameMain возвращается, Surface 2800×1272 создаётся. С публичными ресурсами установленной игры запуск доходит до обращения NativeDialogManager.ShowDialog; этот класс пока отсутствует. Сама деревня в нашем приложении не отображается. Графический эксперимент ещё зависит от установленной игры. STATUS.json описывает проверенные возможности, но не все последние эксперименты; смотреть также журналы original-assets-* и src/.

Актуальный прогресс Codex: CODEX_REPORT.md. Проект договора UI/native: UI_NATIVE_CONTRACT.md.

## Доступные файлы (читать по необходимости)

Корень материалов — родительская папка этого репозитория.
- ../assets-current/ — извлечённые ресурсы (SC, изображения, шрифты и др.). Не сканировать весь многогигабайтный набор без конкретной цели.

- SDK/NDK — ../../../work/android-sdk от корня репозитория; JDK /opt/homebrew/opt/openjdk. Абсолютный путь к workspace указан в стартовом промпте.
