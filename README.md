# Offline Sandbox

**Локальная Android-песочница на базе Clash of Clans 18.647.5.** Деревня, бои и инструменты редактирования с оригинальной графикой и интерфейсом игры.

> Приватный экспериментальный проект. Файлы доступны после входа в GitHub под аккаунтом с доступом к репозиторию. Проект не является официальным продуктом Supercell.

## Что можно делать

- Редактировать уровни войск, заклинаний, героев, питомцев, снаряжения и зданий.
- Проводить локальные бои, сохранять и просматривать повторы.
- Работать с планировками: банк, импорт и экспорт текстовым кодом, восстановление по скриншотам.
- Выбирать оформления деревни и скины при наличии соответствующих ресурсов.
- Использовать инструменты пополнения ресурсов и подкрепления.

Некоторые функции остаются экспериментальными. Наличие пункта в меню не означает, что все сценарии прошли проверку.

## Установка

1. Скачайте **CoC-Sandbox-lite.apk** на Android-телефон или планшет.
2. Откройте файл. При необходимости разрешите установку приложений из выбранного браузера или файлового менеджера и подтвердите установку.
3. Запустите **CoC Sandbox**.

При обновлении устанавливайте APK поверх существующего приложения. Удаление приложения может удалить локальные сохранения. Совместимость обновления требует той же подписи приложения.

### Дополнительный пакет

1. Скачайте **CoC-Sandbox-extras.zip** на устройство.
2. Откройте **Песочница → Планировки → Доп. пакет → Установить**.
3. Выберите ZIP, дождитесь завершения и перезапустите песочницу.

Распаковывать ZIP вручную не нужно. Доппакет расширяет набор ресурсов; Lite предназначена для базового запуска без него. Заранее оставьте место для скачанного ZIP и распакованных файлов — приблизительно 1,7 ГБ дополнительно для распаковки. После успешной установки ZIP можно удалить.

## Требования и ограничения

- Android 8.0+ и процессор ARM64. Сборка не предназначена для iOS или запуска в браузере.
- Рабочие проверки проводились на OnePlus CPH2767 с Android 16. Совместимость со всеми устройствами не подтверждена.
- Загрузчик текущей сборки сохраняет зависимость от установленного официального Clash of Clans. Полностью независимый запуск без оригинального пакета не подтверждён.
- Распознавание планировки по скриншотам приблизительное: проверяйте результат перед использованием.
- Полный пользовательский сценарий установки доппакета и все сочетания скинов, оформлений и боёв ещё требуют проверки.

## Для разработки

Сборка выполняется локальным `build.py` в подготовленном окружении Android SDK/NDK и OpenJDK. `make_single_apk.py` объединяет код и ресурсы; Lite исключает отложенные ресурсы по списку, а доппакет устанавливается отдельно. Исходники обвязки не являются исходным кодом движка Supercell; исходных текстов оригинального движка здесь нет.

Ключи подписи, токены, персональные сохранения и локальные инструменты разработки не следует добавлять в репозиторий. APK и ZIP размещены в **Releases**, отдельно от истории исходников.
